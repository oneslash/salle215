Salle 215 Support

For iPhone and iPad with iOS 26 or later

Need help? Email support@room215.me. Tell us your device, iOS version and what you were doing. Never send your API keys.

Getting started

Try it without an account

On the first screen, tap Explore a sample project. It opens a sample project with traces, metrics, prompts and a review queue. Nothing is sent anywhere.

Connect your Langfuse project

  1. In Langfuse, open your project’s Settings → API Keys and create a key pair.
  2. In Salle 215, tap Connect to Langfuse.
  3. Enter your instance URL, the public key and the secret key. Optionally, enter an environment to show only that environment’s data.

The instance URL must match your project’s region, for example https://cloud.langfuse.com (EU) or https://us.cloud.langfuse.com (US). Self-hosted instances must run Langfuse v4 and use HTTPS.

Common questions

“The API keys were rejected”

Check that both keys belong to the same project and that the instance URL is your project’s region. Keys from an EU project don’t work against the US URL, and the other way around.

“Langfuse’s API limit was reached”

Langfuse limits how many requests an account can make. Salle 215 waits the time Langfuse asks for. Try again in a minute.

A report reached the row limit

Choose a shorter time range on Overview.

Where do my reviews go?

In a connected project, each Good or Needs work rating is saved to that project as a score named salle215-review-thumbs, with any reasons and note you add. Undo removes it. In the sample project, ratings stay on your device.

How do I load more traces?

Scroll down in Traces. More traces load automatically as you approach the bottom. Use the time range and error or slow filters to narrow the list.

How do I switch projects or remove my keys?

Open the project menu at the top of the screen and choose Disconnect. This removes the keys from your device. Then connect to another project.
